# HoYoPass for Firefox（非公式）

原神・崩壊：スターレイル・ゼンレスゾーンゼロの HoYoLAB デイリーログインボーナスと
交換コードを、Firefox を開いておくだけで自動で受け取る拡張機能です。
Chrome 拡張「HoYoPass」の挙動を参考にしたクリーンルーム再実装で、元のコードは含みません。

> **Disclaimer**: 非公式のファンメイドプロジェクトです。COGNOSPHERE / miHoYo（HoYoverse）
> とは一切関係ありません。HoYoLAB の非公開 API を利用しているため、仕様変更で
> 動かなくなることがあります。利用は自己責任でお願いします。

## できること

- **デイリーログインボーナスの自動受取** — 毎日 01:05（お使いの PC の現地時刻）
  ごろに自動実行します。その時刻に Firefox が起動していなくても、次に起動した
  ときに未受取分を自動でキャッチアップするので、深夜に PC をつけておく必要は
  ありません
- **交換コードの自動引き換え** — 3時間ごとに最新のコードを確認し、新しいものを
  順次引き換えます。コード一覧は [hoyo-codes](https://github.com/seriaati/hoyo-codes)
  の公開 API から取得しています
- **ゲームごとの ON / OFF** — プレイしていないタイトルは、ポップアップから
  チェックイン／コード交換を個別に止められます。止めたタイトルはバックグラウンド
  実行からも除外されます
- **ワンクリック手動実行** — ポップアップのボタンから、その場で全タイトルの
  チェックインとコード交換を実行できます
- **状況の可視化** — ポップアップで各タイトルの最終実行結果、有効コード数、
  累計の引き換え件数を確認できます

## 使い方

1. Firefox で HoYoLAB にログインします（一度だけで大丈夫です）
2. 拡張機能をインストールし、ツールバーのアイコンからポップアップを開きます
3. あとは自動です。Firefox を起動するたびに未受取分をキャッチアップし、
   起動中は毎日 01:05 のチェックインと 3時間ごとのコード確認が走ります

初回実行時、過去に手動で交換済みのコードがあると、ゲーム内メールで
「使用済み」の通知が届くことがあります。API の仕様による正常な挙動で、
一度処理したコードは拡張機能内に記録され、次回以降は再送信されません。

## インストール

現在は開発版です。Firefox への一時読み込みで使えます。

1. このリポジトリを取得し、`npm install && npm run build` を実行します
   （ビルド済みの `background.js` / `popup.js` も同梱されているので、
   そのまま読み込むこともできます）
2. Firefox で `about:debugging` →「この Firefox」→「一時的なアドオンを読み込む」
3. このフォルダの `manifest.json` を選びます

**注意**: 一時読み込みは Firefox を再起動すると消えます。再起動後も自動実行
させるには、AMO（addons.mozilla.org）で署名されたパッケージとして
インストールする必要があります（署名対応は今後の課題です）。
`manifest.json` の `browser_specific_settings.gecko.id` は仮の値
（`hoyopass-firefox@aynm.dev`）です。

## プライバシーとセキュリティ

- パスワードや Cookie を拡張機能が読み取ることはありません。外部サーバーへ
  送信することもありません（コード自体が Cookie の値に触れない設計です）
- 通信先は公式の HoYoLAB / HoYoverse API と、コード一覧の取得元である
  hoyo-codes.seria.moe のみです。API の認証は、ブラウザに既にあるログイン
  セッションをブラウザ自身に付けてもらう方式（`credentials: "include"`）で、
  ログイン状態の判定も API の応答で行います
- 設定や受取履歴はすべてお使いの PC のローカル（拡張機能のストレージ）に
  のみ保存されます
- 匿名利用統計を含む、いかなる解析・テレメトリ送信も行いません

  プレイしていないタイトルはポップアップから OFF にしてください
